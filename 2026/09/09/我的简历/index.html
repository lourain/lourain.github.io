    • 引入 qiankun 微前端架构，将核心监测、应急调度等高内聚模块解耦为独立子应用，支持多研发小组并行开发与独立灰度部署。
    • 多局点动态化扩展：针对天津、葫芦岛、石家庄、开封、廊坊、青岛、聊城等多地市局点的深度定制化需求，设计 asyncComponent 异步动态加载机制，将局点特性作为独立仓库发布并按需接入，有效规避多分支合并冲突与维护灾难。

项目 2：燃气综合监管与应急指挥大屏（GIS / 物联网指挥中心）

  • 项目背景：面向各级政府应急管理部门与燃气集团的“一网统管”核心可视化大屏，汇聚城市燃气运行全态势。
  • 核心功能与架构落地：
    • 2D GIS 空间态势感知：基于 2D 地图实现城市全域燃气管网及站点的高密度动态撒点定位；实时跟踪与回放巡检作业车辆运行轨迹及外勤运维人员实时活动态势。
    • 应急调度一体化联动：深度集成海康威视 H5 视频流监控 SDK，支持点位监控实时弹窗轮巡与 PTZ 云台控制；对接现场电话拨号调度 SDK 与 IoT 设备传感器告警系统，实现阈值越限秒级弹窗预警与应急直拨联动。
    • 自适应多比例大屏缩放引擎：攻关超大屏适配难题，自研多比例缩放适配方案，完美支持 16:9（标准展厅屏）、24:9（超宽带鱼屏）、32:9（指挥中心双联大屏） 等多种大中小规格屏幕的自由切换与无损等比缩放，杜绝布局拉伸与模糊。
    • 物料工程化交付：提炼大屏 Echarts 定制图表与地图控件物料，结合低代码平台支持实施人员快速按需组装交付。

项目 3：智伴燃气大模型平台 & 行业文献阅读器（AI-Native / Vibe Coding 实践）

  • 项目背景：为燃气专业领域打造的智能问答平台及海量专业文献智能交互阅读器。
  • 技术亮点与体验优化：
    • 流式渲染与队列调度：基于 SSE (Server-Sent Events) 接入大模型流式输出，自研平滑打字机队列池与渲染调度算法，解决大段文字高频推送下的渲染抖动，并实现智能自适应滚动与用户触摸打断拦截机制。
    • 动态图表卡片渲染：制定领域特定渲染协议，实现大模型根据对话上下文动态调度渲染业务表格、Echarts 图表及告警卡片。
    • Vibe Coding 敏捷交付文献阅读器：在文献阅读器开发中，深度实践 基于 Codex 的 Vibe Coding 敏捷研发模式，通过精细化上下文指令快速完成底层核心逻辑构建；实现将后端全量返回的超长 Markdown 数据按标题颗粒度高效切片，支持首屏秒级渲染、全文关键词检索、多级目录精准锚点定位与正文双向平滑滚动联动。
    • AI 研发规范：结合大模型生成能力，编写工程调试 Rules 与 Harness 测试用例，对 AI 生成代码建立严格质量约束机制。

项目 4：天津第三方施工小程序 & 燃气移动监管 App

  • 跨端与通信机制：采用 UniApp + 原生容器（Android壳）+ H5 混合架构，在 H5 端自主封装统一 JSBridge 双向通信层，实现与原生容器底层接口（定位、相机、本地文件系统）的安全高效交互。
  • 工程亮点：集成 Webview 嵌入式地图定位看护、施工现场实时拍照/录像打卡上传、横屏手写电子签名等关键现场施工管理能力。
